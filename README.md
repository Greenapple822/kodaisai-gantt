# 工大祭 設営ガントチャート

設営・本番・撤収の作業計画を1枚の図にするツールです。
**当日見るだけの人は `dist/index.html` をダブルクリックしてください。** それだけで開きます。

---

## 1. 予定を変更したいとき

直す場所は **`data/schedule.csv` の1箇所だけ** です。
Excel でも Google スプレッドシートでも、メモ帳でも開けます。

**CSVを直接さわりたくない人は、画面の「編集」タブから直せます**（→ 6-3）。
編集した結果はCSVとして書き出せるので、最後に反映する場所はどちらの方法でも `schedule.csv` 1枚のままです。

| 列 | 何を書くか | 例 |
|---|---|---|
| `id` | かぶらない名前。班の頭文字＋番号で十分 | `S3` |
| `team` | `映像` / `音響` / `照明` / `全班` のどれか | `音響` |
| `area` | 場所。`data/layout.json` にある id を書く | `stage` |
| `task` | 作業名。**12文字以内**。長いと図で「…」になる | `配線・結線` |
| `start` | 開始時刻 `HH:MM` | `10:00` |
| `end` | 終了時刻 `HH:MM` | `11:00` |
| `owner` | 担当者。複数なら `・` で区切る | `山田・伊藤` |
| `depends` | 先に終わってないと始められない作業の `id`。複数なら `,` で区切る | `S1,S2` |
| `note` | 備考。空でよい | `脚立2台使用` |
| `kind` | 空 = ふつうの作業 / `milestone` / `resource`（下記） | |

### `kind` の使い分け

- **空欄**：ふつうの作業。班のレーンにバーで出る
- **`milestone`**：全体の節目（電源投入・音出し可能・通しリハ開始・開場）。
  `start` と `end` を同じ時刻にする。図では全レーンを貫く赤い縦破線になる
- **`resource`**：取り合いになる資源（ステージ占有・脚立・電源など）。
  図の一番下の「共有リソース」レーンに出る。誰かと誰かがぶつかってないか確認するための行

### 使える `area`

`data/layout.json` に書いてある id だけです。いまは
`stage`（ステージ上）/ `wingL`（下手袖）/ `wingR`（上手袖）/ `backstage`（楽屋）/
`floor`（客席）/ `foh`（客席後方・卓）/ `storage`（機材置場）。

会場が変わった年は `data/layout.json` の座標だけ差し替えれば図が追従します。

## 2. 変更を反映する（配布用を作り直す）

CSV を直したら、ターミナルでプロジェクトのフォルダに入って1行打つだけです。

```bash
python3 tools/build.py
```

`dist/index.html` が作り直されます。あとはこの1ファイルを部員に配ってください。
（Python は macOS に最初から入っています。npm も Node.js も要りません）

> **なぜビルドが要るの？**
> HTML をダブルクリックで開くと、ブラウザの制限で CSV を読みに行けません。
> そこで CSV と JSON を HTML の中に文字列として焼き込んでいます。

---

## 3. データが間違っているとき

図の上にオレンジ色の枠で「データの確認が必要です」と出ます。
存在しない `area`、見つからない `depends`、`end` が `start` より前、などをその場で教えてくれます。
出たら CSV を直して、もう一度 `python3 tools/build.py` してください。

---

## 4. 開発するとき

`src/` を直接ダブルクリックしても動きません（同じブラウザの制限のため）。

```bash
python3 -m http.server 8000
```

を叩いて `http://localhost:8000/src/` を開いてください。
この状態なら CSV を保存 → ブラウザを再読み込みするだけで反映されます。
配る前には必ず `python3 tools/build.py` を実行してください。

## 6. 画面の使い方

上のタブで2つのビューを切り替えます。

### ビュー1　班別ガント

班ごとの横棒グラフです。一番下の「共有リソース」は、ステージ占有・脚立・電源など
取り合いになるものを並べた行です。赤い縦の破線がマイルストーン（電源投入・音出し可能など）。
バーにカーソルを乗せると、場所・担当・前提作業・備考が出ます。

### ビュー3　平面図タイムライン

**多目的ホールのどこに、どの班が、その時刻にいるか**を示す図です。

- **▶ 再生**：15分ずつ自動で時間が進みます。最後まで行くと頭に戻ります
- **◀ ▶ ボタン / ← → キー / スライダー**：手で時刻を動かします
- 色の付いた札がその時刻に作業している班。**作業がないエリアは灰色**のままです
- エリアの右上に「2班」のように何班いるかが出ます。**3班以上になると枠が赤くなります**
  （ぶつかりそうな場所を見つけるための表示です）
- エリアが狭くて札を出しきれないときは「+1件」と出ます。中身は右のリストで全部読めます
- 右側に、その時刻の作業一覧・使用中の共有リソース・直前と次のマイルストーンが出ます

### 6-3　編集タブ

CSVを開かずに、画面の表で直せます。

**表の上にプレビューが出ます。** 直した結果がその場で図になるので、
別のタブに移動して確認する必要はありません。

- 初期状態は **「両方」**。班別ガントと平面図が横に並びます（スマホでは上下）。
  時間の前後と「その時刻に誰がどこにいるか」を同時に確かめられます。
  片方だけ大きく見たいときは **班別ガント／平面図** に切り替えます
  （平面図はプレビューの中でも再生できます）
- **行を選ぶと、その作業がプレビューの中で濃く光ります**（他は薄くなります）。
  平面図を見ているときは、その作業が始まる時刻に自動で飛びます
- 表を下にスクロールしてもプレビューは画面の上に残ります
- 邪魔なときは **折りたたむ** で閉じられます（スマホでは追従せず、表の上に置かれます）

- **種別**：作業／マイルストーン／共有リソース。マイルストーンの行は終了時刻を持ちません（開始に揃い、入力欄が固定されます）
- **班・場所**：選ぶだけです。場所の選択肢は `layout.json` から作られます
- **開始・終了**：時刻の入力欄です。スマホなら時計のダイヤルが出ます
- **担当**：複数なら `・` 区切り（例：`山田・佐藤`）
- **前提**：先に終わっている必要がある作業のIDを `,` 区切り（例：`S1,S2`）
- **↑ ↓ 複製 削除**：行の並べ替えと増減。複製すると新しいIDが自動で振られます。
  **削除は確認なしで消えますが、画面の下に出る「元に戻す」で戻せます**（15秒間）
- **IDを変えると、それを指している「前提」も自動で書き換わります**
- **＋ 作業を追加**：空の行を足します
- おかしいところがある行は**オレンジ色**になり、上に理由が出ます（時刻の前後が逆、存在しない場所、見つからない前提IDなど）
- スマホでは1行が1枚のカードになるので、横スクロールせずに直せます

### 6-4　案（パターン）の自動保存

編集内容は**「案」として自動で保存されます。** 保存ボタンはありません。

- 「配布時の予定」を開いたまま何か直すと、**自動的に「案1」ができて**そこに保存されます
- 上の欄で **案を切り替え**られます。「配布時の予定」はいつでも元のまま残っています
- **名前を付けられます**（例：`雨天パターン`、`機材が間に合わない場合`）。
  右の欄に打って Enter か、他をクリックすれば変わります
- **＋ 別の案として保存**：いまの状態をコピーして別の案にします。
  1つの案を土台に枝分かれさせたいときに使います
- **この案を削除**：消した直後に「元に戻す」が出ます（15秒間）
- 右端に **自動保存 HH:MM** と出ます。ブラウザを閉じても次に開いたとき続きから出ます

**⚠ 案はその端末のブラウザにだけ残ります。** 自分のパソコンで作った案は、
他の部員の画面にも、自分のスマホにも出てきません。
案を開いている間は画面の上に青い帯が出てそのことを知らせます。
（プライベートウインドウなど保存できない画面では、その旨が帯に出ます）

全員の分に反映したいときは、下の手順でCSVを書き出して `schedule.csv` に貼り、`sh tools/publish.sh` を実行してください。

**みんなの分に反映するには**

1. 「編集」タブの **CSVを書き出す** を押す
2. 出てきた内容を **コピー**、または **ダウンロード**（共有リンクで開いた場合は保存の確認が出ます。
   保存ボタンが出ていない画面では「コピー」を使ってください）
3. `data/schedule.csv` にまるごと貼り付けて保存
4. `sh tools/publish.sh` を実行する（全員の画面に反映されます）

元の予定を見たいときは、案の欄で **「配布時の予定」** を選びます。
案は消えないので、あとで選び直せば続きから編集できます。

## 7. PDFで配る・貼り出す

右上の **「PDFで書き出す（A4横）」** を押すと印刷画面が出ます。
送信先（プリンタ）で **「PDFに保存」** を選べばPDFファイルになります。

- 紙に出るのは **班別ガント1枚（A4横）** です。班の色もそのまま出ます
- **共有リンクで開いた場合、ボタンから印刷画面が開かないことがあります。**
  そのときは画面に案内が出るので、ブラウザのメニューから印刷（⌘P / Ctrl+P）を選んでください。
  配布版（`dist/index.html`）をダブルクリックで開いた場合はボタンがそのまま使えます
- 平面図タイムラインは時刻で変わるものなので紙には出ません
- どちらのタブを開いていても、出るのは必ず班別ガントです
- 右下に余白があるので、当日の書き込み欄に使えます

### 部員に配るリンク

**<https://greenapple822.github.io/kodaisai-gantt/>**

- **ログイン不要**。ChromeでもSafariでもスマホでも、リンクを踏むだけで開きます
- アプリのインストールも、アカウントも要りません
- 平面図は指で横にスクロールできます

### 予定を変えて、全員に反映する

`data/schedule.csv` を直したら、ターミナルでプロジェクトのフォルダに入って1行打つだけです。

```bash
sh tools/publish.sh
```

図の作り直し → 記録 → GitHubへ送信 まで全部やります。**1〜2分で公開ページが新しくなります。**
変更の内容をメモに残したいときは、後ろに付けてください。

```bash
sh tools/publish.sh "照明の吊り込みを30分延長"
```

図もPDFも平面図も元は同じ `schedule.csv` 1枚なので、直す場所は今までどおり1箇所だけです。

- 公開されているのは `docs/` フォルダの中身です。ここは `tools/build.py` が自動で作るので、手で触らないでください
